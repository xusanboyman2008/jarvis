# Barehands Gestures & Hotkey Matrix

## Core Hand Gestures
- **Tap (Quick Pinch):** Open cards, expand orbs, select items
- **Pinch & Drag:** Move glass cards across 3D space
- **Hold Still while Moving:** Rotate cards and 3D objects in 3D pitch/yaw
- **Two Hands:** Pinch with both hands to scale / resize cards
- **Flick:** Throw card off-screen to dismiss
- **Clap (Palms Together):** Clean wipe / reset entire stage
- **The Claw:** Open hand -> claw pose -> hold 2s -> snap shut to force-pull far cards

## Keyboard Shortcuts
- **C:** Cycle camera sources (if multi-camera rig connected)
- **R:** Re-scan note directory trees from disk
- **D:** Toggle debug tracking HUD and landmark mesh
- **F:** Fullscreen toggle
